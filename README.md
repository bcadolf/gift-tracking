**Welcome to Gift Tracker. This project was born out a desire to end the scramble of which gift was mentioned in what chat.**

This project is still a work in progress. Ideas are churning. Inital routing works, you can create groups add, delete and edit members, still no group edits or gift adding. But until then enjoy!

### [Production Live Site](https://gift-tracking-phi.vercel.app/)

## Tech Stack

_Framework: Next.js_
_Library: React_
_Languages: TypeScript, SQL_
_Database: Neon PostgreSQL_
_ORM: Drizzle_
_Host: Vercel_
_Version/Source Control: Git/Github_
